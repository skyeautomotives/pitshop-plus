# Pitstop Plus brand files

All files are vector (SVG). Lettering is Montserrat Black/ExtraBold, converted to outlines, so no font is needed.

| File | Use |
|---|---|
| `pitstop-plus.svg` | **Main logo** (light backgrounds): gauge + PITSTOP PLUS + "by Skye Automotives" |
| `pitstop-plus-dark.svg` | Main logo for dark/navy backgrounds |
| `pitstop-plus-flag.svg` | Alternate logo with a chequered pit-lane flag after PLUS |
| `pitstop-plus-flag-dark.svg` | Alternate logo, dark backgrounds |
| `emblem-white.svg` | Gauge mark alone, white, for dark headers |
| `app-icon.svg` | Square app icon (Windows, Android, browser tab) |

Colours: ink `#101820`, orange `#FFB02E` → `#FF6B24`, needle red `#E3262F`, navy `#0F1F4B`.
